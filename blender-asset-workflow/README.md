# blender-asset-workflow (legacy)

Исходная узкая версия скилла: high-poly оружейные ассеты в Blender/Krita по фотографиям и размерам
(сквозные стволы и шахты, внутренности затвора, bevel, слои под текстурирование).

Папка сохранена без изменений для существующего проекта. Общий навык для всех архетипов
(архитектура, персонажи, оружие, пропсы, транспорт, окружение) с GitHub-доставкой находится
в корне репозитория: [../SKILL.md](../SKILL.md). Знания этой версии перенесены туда:

- `references/construction-standards.md` + `references/archetypes.md` → `../references/hard-surface.md`
- `references/animation.md` → `../references/rig-and-animation.md`
- `references/materials-delivery.md` → `../references/texturing-pbr.md`, `../references/lookdev-and-proofs.md`, `../references/delivery-and-handoff.md`
- `scripts/audit_blend.py` и `references/lessons-pm.md` используются общим скиллом без изменений
