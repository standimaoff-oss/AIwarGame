# AI WAR GAME — процедурная тактическая стратегия

Браузерный прототип стратегии в реальном времени на Three.js. В игре есть тактический 3D-полигон, процедурный рельеф и окружение, Россия и США как две игровые стороны, выбор подразделений и приказы движения, разрушаемые здания, огонь, дым, искры, повреждения узлов техники и расход боекомплекта. Сборка создаёт автономный одностраничный файл [`AI_WAR_GAME.html`](AI_WAR_GAME.html), а отдельная библиотека содержит готовые GLB-модели с встроенными PBR-текстурами.

## Запуск

```bash
npm install
npm run dev
```

Сборка production-версии и автономного HTML-файла: `npm run build`. Готовая игра появится в корне проекта как `AI_WAR_GAME.html`; CSS и JS встроены внутрь файла, внешние runtime-файлы не требуются.

## Управление прототипом

- **ЛКМ** по подразделению — выбрать; по зданию — назначить цель тестового воздействия.
- **ПКМ** по земле — приказать выбранному подразделению переместиться. Перетаскивание ПКМ панорамирует камеру.
- **Колесо мыши** — приблизить или отдалить карту; **ЛКМ + перетаскивание** — повернуть обзор.
- На сенсорном экране коснитесь подразделения для выбора, затем коснитесь земли для приказа движения; жесты камеры обрабатываются OrbitControls.
- Мини-карта перемещает камеру в выбранную точку.
- Панель «Симуляция» позволяет задать силу воздействия, управлять видимостью дыма/огня и ветром, восстановить сценарий.
- Выберите технику и нажмите **«Экспорт техники в GLB»**, чтобы скачать сценовую модель выбранной машины.

## Что уже реализовано

- Локальная генерация 3D-полигона без сетевых текстур: сетка рельефа 6 × 6 км, лес, река, дороги/мост, застройка и две игровые стороны.
- Внутриигровые модели и шесть отдельных GLB-ассетов техники; узлы и детали разделены на именованные mesh-объекты.
- Выбор объектов, приказ перемещения, карточка подразделения, мини-карта и журнал событий.
- Повреждение корпуса, двигателя, ходовой, вооружения, топливной системы и БК. Расход боеприпасов при тестовом выстреле; неисправности отражаются в панели и влияют на состояние/движение техники.
- Повреждение зданий: обугливание, частичное разрушение, обломки и полное разрушение корпуса.
- Эффекты на спрайтах и геометрии: вспышка, ударное кольцо, пыль, искры, очаги пламени, дымовые клубы, ветер и мерцание света.

## GLB-библиотека

В `assets/models/` лежат готовые бинарные модели с геометрией и встроенными PNG-картами PBR: цвет/камуфляж, normal и metallic-roughness. Ассеты параметрические и предназначены для игрового прототипа — это не фотограмметрия и не официальные CAD-модели производителя.

- [Т-90М](assets/models/t-90m.glb) · [БМП-3](assets/models/bmp-3.glb) · [Урал-4320](assets/models/ural-4320.glb)
- [M1A2 Abrams](assets/models/m1a2-abrams.glb) · [M2 Bradley](assets/models/m2-bradley.glb) · [HMMWV](assets/models/hmmwv.glb)

Перегенерация ассетов: `python -m pip install -r scripts/requirements-assets.txt`, затем `python scripts/generate_glb_assets.py`. Описание сцен и дальнейший план — [`docs/GAME_CONCEPT.md`](docs/GAME_CONCEPT.md).

> Это расширяемый игровой прототип, а не готовый коммерческий симулятор: сейчас доступна одна тестовая карта и демонстрационная симуляция. Кампания, ИИ противника, сохранения, сетевой режим и физика столкновений остаются следующими этапами.
