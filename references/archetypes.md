## Быстрые критерии «что ломает реализм»

| Архетип | Самые частые провалы |
|---|---|
| Архитектура | коробка без толщины стен, лестница с неверной геометрией ступеней, окно как плоскость, отсутствие интерьера/перекрытий, одинаковые окна без вариаций, грязь без логики стока воды |
| Персонаж | пропорции «на глаз», симметричное лицо, глаза без толщины век, волосы прорезают голову, одежда как обёртка без швов, петли топологии не проходят через суставы |
| Hard surface | заглушка вместо сквозного канала, фаска на бруске вместо профиля, нарисованный крепеж, «плавающие» кабели, разный радиус кромок у соседних панелей |
| Пропсы | нулевая толщина стенок, отсутствие соединений, закрытые ящики без внутренностей, неверный масштаб к руке/столу, износ «везде» |
| Транспорт | разные зазоры панелей по одной линии, колёса без боковины и тормозов, фара как один стеклянный объект, отсутствие салона, грязь равномерным слоем |
| Окружение | одинаковые камни и деревья без вариаций, равномерный случайный scatter, вертикальные склоны с травой, вода без береговой линии, тайлы с видимым швом |

## Смешанные ассеты

- Персонаж + оружие/инструмент: единый масштаб (рост человека и длина предмета), хват с реальной контактной зоной и деформацией кисти, оружие как отдельный ассет с собственным origin, чтобы его можно было передать в другую руку/сцену.
- Интерьер + мебель + пропсы: единый texel density, общий набор trim, согласованный свет, планировка проходов (двери не упираются в мебель).
- Здание + окружение: посадка на рельеф с фундаментом и отмосткой, дорожки и растительность не пересекают конструкции, дренаж и сток воды согласованы.
- Транспорт + персонаж: посадка, высота седла/руля/педалей под рост, видимость через стекло.
